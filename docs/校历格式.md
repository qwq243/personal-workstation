# 校历格式

校历回答一个问题：**某一天「上不上课 / 第几教学周 / 是不是放假」**。

这个模块的价值是**算法**（教学周现算、假期不排课、调休的处理），不是某一所学校的日期 ——
所以代码里的内置校历是空的，日期全部来自数据文件：

```
server/data/school-calendar.json      ← 你要维护的就是它
```

文件不存在时会按空结构自动播种一份出来，直接编辑即可（或让页面的日历视图读它）。
**换学年只改这个文件，不用动代码。**

## 算法（读文件前先知道它怎么用这些字段）

- **教学周**：从某个学期的 `start` 那天算第 1 周的第 1 天，每 7 天一周；`weeks` 是总周数，
  超出范围的日期不算教学周。
- **上课判定**：教学周内、**周一到周五**、且当天没有被「停课型事件 / 法定节假日」覆盖 → 上课。
  周末默认不上课 —— 除非它出现在 `workdays` 里（调休上班）。
- **优先级**（同一天撞上多条时取最高）：`workdays`（调休上班）> `holidays`（法定节假日）>
  学期内的 `events`（按 `kind` 排序：vacation → exam → event → register）> 普通教学日。
- **`week` 只在工作日给值**：周末返回的是 `{ kind: 'rest' }`，`week` 为 `null`。
  这是刻意的 —— 「周六属于第 8 周」在课表上没有意义。

## 字段

```jsonc
{
  "version": 1,
  "school": "某某大学",          // 只用于显示
  "note": "数据来源说明",         // 只用于显示
  "semesters": [
    {
      "id": "2026-2027-1",       // 学期标识（学期内唯一即可）
      "name": "第一学期",          // 显示名
      "start": "2026-09-07",     // 第 1 教学周的第 1 天（通常是周一）
      "end": "2027-01-15",       // 学期最后一天
      "weeks": 19,               // 总教学周数
      "events": [
        {
          "name": "报到",
          "start": "2026-09-05",
          "end": "2026-09-06",
          "kind": "register",     // vacation | exam | event | register
          "suspend": true,         // 可选：这天停不停课。不写 = 除 event 外默认停
          "overlay": false,        // 可选：true = 只贴标签，不改变当天性质
          "tag": "军训",           // 可选：overlay 时显示的标签
          "note": "补充说明"        // 可选
        }
      ]
    }
  ],
  "holidays": [
    { "name": "国庆节", "start": "2026-10-01", "end": "2026-10-07", "estimated": false }
  ],
  "workdays": [
    { "date": "2026-10-10", "name": "国庆调休上课" }
  ]
}
```

### 什么时候用 `overlay`

`overlay: true` 表示「这几天**照常上课**，只是多一个可看的备注」。典型场景：新生军训期间，
高年级照常上课 —— 这几天仍然是「上课」，只是标签里多一个「军训」。

不写 `overlay` 的事件是**覆盖型**：它会改变当天的性质（比如「校运会停课三天」）。

### `estimated` 是干什么的

法定节假日的具体安排要等国务院办公厅通知；在通知出来之前，可以按惯例先填一份并标
`estimated: true`。**它只影响显示**（页面上会标注「推算」），不影响判定逻辑。

### 调休为什么单列

`workdays` 里的日期是「**周末但要上课**」的日子。它必须优先级最高 —— 因为按星期几判断的话
周末本来是「不上课」，而调休恰好相反。
