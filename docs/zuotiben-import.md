# 做题本：题库池怎么导入（试题册 / 解析册）

做题本（`#/zuotiben`）本体只要求「题一条一条进来」（智能体用 MCP `add_problems` 灌题就能用）。
**题库池是可选的**，它只服务一件事：**推荐同类题**（`list_problem_pool` / `suggest_problems`）——
要能按章检索题目、并知道每道题的原文落在哪份文件的哪一章（`ref`），所以需要两份结构化 markdown。

题干与解析都是别人的版权物，**不随仓库分发**：自己买书，把两份材料摆成下面这种结构，
再把路径填进配置。解析器是 `server/lib/kaproblems.mjs`，本文就是它的格式契约。

## 一、两份文件、一个目录

```
<题库目录>/
  试题册.md     ← 只有题干与选项
  解析册.md     ← 只有答案与解析
```

两份都按「章」组织，**章号要对得上**。对不上的那一章：题还在，但答案是空的
（`hasSolution=false`），推荐同类题默认不会把它推给人做。

## 二、格式要求

### 章标题

`# 第 3 章 <章标题>` —— `#` 的个数不限（0~3 个都认），「第 / 章 / 标题」之间的空格也不限。
解析册的章标题同样写法，**不要求与试题册同级**。

### 目录行

`第3章 <章标题> …… 5` 这种目录行**必须先被排掉**：解析器按「行里有 `…` 或连续三个点」
判定并跳过。不排掉的后果很重 —— 「第1章」的第一次出现被算成目录那行，整本正文会被判成
强化篇，于是一道题都解析不出来。自己转 markdown 时：要么整段删掉目录，要么让目录行带 `…`。

### 书眉（解析册尤其常见）

页眉每页重复印一遍章名，于是**同一章号会连续出现好几次**。解析器按「章号与上一段相同就跳过」
合并，重复的书眉是安全的；但别把章号写错，否则会被当成新章、把章从中间截断。

同一本书分「基础篇 / 强化篇」两段时章号会从头再来一次，解析器按「**章号回落**」判篇。
**目前只认基础篇**（强化篇的切分逻辑一模一样，等要用时放开）。

### 题块（试题册）

```
1. 题干从这里开始……            ← 行首数字 + `.` / `．`，点后面要有空格
(A) 选项一  (B) 选项二         ← 选项行；一行里塞多个选项会被拆开
```

选项也可以跟题干挤在同一行（`…（ ）. (A) … (B) …`），解析器会从题干里再切一刀补回来。
题块内不以题号开头的行都算题干的续行。

### 题块（解析册）—— 五种开头都要认识

```
## 1.【答案】 (A)      ← 答案就在标记后面
4.【分析】……           ← 只有分析，没有单独答案
8.【解析】……           ← 解析正文
9.【证明】……
3.【解】……
```

`【答案】【解析】【分析】【证明】【解】` 这五种标记解析器逐个认，一章里混着用很正常 ——
只认 `【答案】` 的话会漏掉一半题（2026-09-27 实测：一章 12 题只抓到 6 题）。

### 填空横线

填空位写 `______`（三个以上下划线）或 `\_\_\_\_`（LaTeX 转义）都行：读进来会统一还原成
裸下划线，「展开答案回填空位」才认得出那个空位。

## 三、怎么指路（配置）

```jsonc
// server/config.json
{
  "zuotiben": {
    "pool": {
      "dir": "D:/你的题库目录",   // 正斜杠
      "problems": "试题册.md",    // 相对 dir 的文件名
      "solutions": "解析册.md"
    }
  }
}
```

三样**都要填**（只填目录的话，不知道该读哪两份文件）。改完**不用重启边车** ——
配置与两份文件的修改时间会一起用来失效缓存。

没配、或文件不在时，池子是空的但**不会报错**：

- `list_problem_pool` 直接说「没配题库目录（配置项 …）」或「题库文件不存在：…」；
- `suggest_problems` 会把同一句话接在「没挑出候选题」的原因后面。

## 四、`ref`（溯源）字段

每道题都带一份结构化出处：推荐同类题按它筛章、去重按它比、回查原文按它找。

| 字段 | 含义 |
|---|---|
| `book` | 题册名 = 试题册文件名去掉 `.md` |
| `part` | 篇（目前恒为 `基础篇`） |
| `chapter` / `chapterTitle` | 章号 / 章标题 |
| `no` | 章内题号 |
| `label` | 印在题号旁的那句，形如「某题册·基础篇 第3章 第12题」 |
| `files` | 回查落点：`<目录名>/试题册.md#第3章`（解析册同理） |

题 id 是 `jc<章号>-<题号>`（如 `jc3-12`）—— 「别重复出题」按它去重，
所以同一份试题册里**同一章的题号不要重号**。

## 五、一道题都没解析出来？按这个顺序查

1. 章标题是否被目录行顶掉了（表现：整本为零，或全被判成强化篇）；
2. 章号在解析册里对不对得上（表现：题都在，但解析齐全数是 0）；
3. 题块开头是不是「数字 + `.`/`．` + 空格」（`12、` 这种顿号开头不认）；
4. 解析册的标记是不是写成了不认的样子（如 `【详解】`）—— 换成上面五种之一。
