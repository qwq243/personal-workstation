# 工作站设计规范（Design System v2）

> 调性：**清爽理性 · 内容优先 · 轻量现代**。学生效率工具，不是营销页——克制用色，靠层次和留白取胜，模块专属色只做点缀。
>
> 唯一事实源：`src/styles/tokens.css`（本文件是它的文字说明）。组件样式只允许引用令牌变量，禁止新增硬编码颜色。
>
> v2 变更：主色由墨绿改回**靛蓝**；图标回到 Element Plus 矢量单轨（仅保留一枚程序生成的品牌主图标）；EP 浅色映射改为挂在 `html[data-theme='light']`（见 §5）。

## 1. 配色

### 品牌主色（靛蓝）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--ws-accent` | `#4f46e5` | `#7c83ff` | 主按钮、激活态、强调数字 |
| `--ws-accent-hover` | `#4338ca` | `#6f76ff` | 悬停 |
| `--ws-accent-soft` | `#eef2ff` | `#1e2140` | 导航激活软底、标签软底 |
| `--ws-accent-ring` | 18% 透明 | 25% 透明 | 焦点环、选中底、logo 落影 |
| `--ws-accent-grad-end` | `#818cf8` | 同左 | 品牌渐变末端 |
| `--ws-on-accent` | `#ffffff` | `#ffffff` | 压在主色实底上的前景 |

主色 50–400 梯级（`--ws-accent-50/100/200/300/400`）供软底与描边取用；`--ws-accent-600` 同 `--ws-accent`。

压语义色实底的前景用 `--ws-on-solid`（浅深均为 `#ffffff`）。

### 模块专属色

成长 `--ws-module-growth` `#166534`（深色 `#4ade80`） · 办公 `--ws-module-office` `#0f766e`（深色 `#2dd4bf`） · 学习 `--ws-module-study` `#4f46e5` · 待办 `--ws-module-todo` `#0ea5e9` · 校内 `--ws-module-campus` `#8b5cf6`（深色自动换浅亮版）。
模块 `color` 字段现值：每日看板 `#0ea5e9` · 日历日程 `#0f766e` · 模型用量 `#d97706` · 规划台 `#4f46e5` · 英语学习 `#4f46e5` · 知识库 `#7c3aed` · 语音随记 `#e11d48` · 进程守护 `#d97706` · 运行与自启 `#0891b2`。
**只用于**：卡片顶部描边、徽标、统计数字、插件卡点缀。不做大面填充。
注：背单词的 `#4f46e5` 与主色同值（历史遗留），语义上等于"学习组 = 品牌主色"，暂不改动。

大模块分组（`MODULE_GROUPS`，同时也是左栏顺序）：**成长** `#166534` → **办公** `#0f766e` → **学习** `#4f46e5` → **待办** `#0ea5e9` → **校内** `#8b5cf6`（最后一组只是给校内类模块预留的空位）。没有 `category` 的功能是置顶入口（现为「进程守护」与「运行与自启」）。

### 日历课程色阶（`--ws-cal-1…8` / `--ws-cal-N-fg`）

日历要「同一门课一眼认出、不同课能区分」，这是唯一需要多色并置的场景，所以单列一组令牌（浅色低饱和软底 + 同色相深前景，深色压深底 + 提亮前景）。取 8 组而不是 6：一学期课表通常 6~10 门，6 组必然撞色。

| | 色相 | 浅底 / 浅前景 | 深底 / 深前景 |
|---|---|---|---|
| 1 | 靛蓝 | `#eef2ff` / `#4338ca` | `#1e2140` / `#a5b4fc` |
| 2 | 青 | `#ecfeff` / `#0e7490` | `#0c2b33` / `#67e8f9` |
| 3 | 绿 | `#ecfdf5` / `#047857` | `#0f2a20` / `#6ee7b7` |
| 4 | 琥珀 | `#fffbeb` / `#b45309` | `#2b2312` / `#fcd34d` |
| 5 | 玫红 | `#fef2f2` / `#b91c1c` | `#2b1618` / `#fca5a5` |
| 6 | 紫 | `#f5f3ff` / `#6d28d9` | `#211b3a` / `#c4b5fd` |
| 7 | 石板灰 | `#f1f5f9` / `#334155` | `#1e2630` / `#cbd5e1` |
| 8 | 桃粉 | `#fdf2f8` / `#be185d` | `#2a1622` / `#f9a8d4` |

课程 → 色号：把**本学期课表里出现过的课程名排序后轮流取色阶**（`CalendarView.vue` 的 `hueMap`），取色顺序 `1,4,3,5,2,8,7,6` —— 相邻两门课在名单里往往也相邻，按这个顺序取色能保证它们对比明显。同一门课在各处永远同色；课程数不超过色阶组数时两两不同色。不用名字哈希——实测一学期十几门课哈希到 6 个桶里必然挤成一团，满屏一片同色。
**只准课程块用**，别扩散到其它组件。

## 2. 字体

系统字族（零加载成本，保"双击即用"），代码/数字用 `--ws-mono`。

| 令牌 | 大小 | 用途 | 字重 |
|---|---|---|---|
| `--ws-fs-xl` | 28px | 页面大标题（hero） | 700 |
| `--ws-fs-lg` | 20px | 区块/页面标题 | 650–700 |
| `--ws-fs-md` | 16px | 卡片标题 | 600–650 |
| `--ws-fs-base` | 14px | 正文基准 | 400 |
| `--ws-fs-sm` | 13px | 辅助文字 | 400 |
| `--ws-fs-xs` | 12px | 说明文字 | 400 |

小于 12px 只用于徽标/角标（11px）。

## 3. 间距 · 圆角 · 阴影

- **间距**：4px 基网 `--ws-space-1…14`（4/8/12/16/20/24/32/40/56）。页边距 28/32，卡片内边距 20，卡片间距 16。
- **圆角**：`--ws-radius-sm` 8（控件/导航项）· `--ws-radius` 12（卡片/弹窗）· `--ws-radius-lg` 16（大卡片/图标砖）· `--ws-radius-pill` 999（胶囊）。
- **阴影**：三级 `--ws-shadow-1`（卡片静止）/ `-2`（悬停浮起）/ `-3`（弹窗浮层）。旧别名 `--ws-shadow-sm/shadow/shadow-lg` 仍可用。

## 4. 动效

120–200ms ease-out；hover 位移 ≤3px；保留 `prefers-reduced-motion` 全局降级；路由切换不用 JS transition（可靠性优先，见 App.vue 注释）。

## 5. Element Plus 对齐

EP 令牌在 `tokens.css` 全量映射（`--el-color-primary` 全梯级 + 语义色 + 文字/边框/背景/填充）。

**关键实现细节**：浅色映射必须挂在 `html[data-theme='light']` 而不是 `:root`——EP 组件 chunk 的 css-vars 也是 `:root` 且按需后加载，同优先级会被盖掉；`html[data-theme='light']` 优先级 (0,1,1) 与加载顺序无关。深色同理在 `html[data-theme='dark']`。

浅色主色 `#4f46e5` 对比度足够，深色主色 `#7c83ff` 压白字亦清晰——两侧实底按钮前景统一 `--ws-on-accent`（`#ffffff`），不再需要额外的按钮文字色覆盖规则。

## 6. 图标

**单轨制：全部使用 Element Plus 线性矢量**，全局白名单在 `src/main.ts`（import + `ICONS` 映射两处，新增图标必须同步）。**禁用 emoji**。

唯一例外是**品牌主图标**（侧边栏左上角 logo）：

- 程序生成的图片（生成脚本没有随仓库分发 —— 要重做就自己准备，配方见下）。
- 配方：**透明底 + 圆角玻璃砖 + 靛蓝→紫渐变 + 白色 WS 字母浮雕**（与主色同色相，实测平均 hue 240° vs 主色 243°）。
- 产物 `src/assets/brand/ws-logo.webp`（256px，约 10KB）。
- `AppShell.vue` 直接 import 该 webp；落影用 `filter: drop-shadow(0 4px 10px var(--ws-accent-ring))` 跟随主题。
- 图像生成常把"透明底"画成**不透明棋盘格**，脚本按「低彩度+高亮且与画面边缘连通」判定背景并抠除，顺带抹掉生成图右下角水印；再按 alpha 包围盒裁正、居中、输出正方形。

其它：心情评分用 ★ 字符 + `--ws-warn` 着色（文本字形，跨端一致）；el-rate 负责录入。

## 7. 新增功能样式清单

1. 颜色/字号/间距/圆角一律引用 `tokens.css` 变量；要新颜色先加令牌。
2. 模块色自选语义：`color` 字段写 hex（TS 里写值，CSS 里写变量），参考 §1 模块专属色。
3. 图标：查 `main.ts` 白名单，缺了就加（import + 映射两处）。不走生成图片流程。
4. 空状态用 `<EmptyState>`，`icon` 传 EP 图标名（默认 `Box`）。
5. 改完跑：构建 + `vue-tsc --noEmit`；视觉改动自己截图看一眼（验收方法见 [verifying.md](verifying.md)）。

## 8. 命名惯例

**页面名与代码名分工：页面 / 导航 / 标题用中文，id、文件名、路由用英文领域名。** 这条原先在多个 `module.ts` 头注释里各写了一遍，现收在这里，模块头注释不再重复。

- 例：`memo` = 语音随记 · `wiki` = 知识库 · `plan` = 规划台 · `vocab` = 英语学习 · `guard` = 进程守护（路由是更好读的 `#/process-guard`，id 要短因为它同时是存储命名空间）。
- 同一领域的几种写法互相对应（分隔符可差），一处改名要一起改：目录 / 文件名 ↔ `server/lib/*.mjs` 能力层 ↔ `/api/*` 前缀 ↔ `#/` 路由。例：`memo` ↔ `server/lib/memo.mjs` ↔ `/api/memo/*` ↔ `#/memo`；`wiki` ↔ `server/lib/wiki*.mjs` ↔ `/api/wiki/*` ↔ `#/wiki`。
- `id` 同时是路由前缀与本地存储命名空间，**定下就别改**（见 [EXTENDING.md](EXTENDING.md) §1.1）。
