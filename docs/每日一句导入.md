# 每日一句：怎么导入自己的句库

「每日一句」是一个**容器**：它带进度逻辑（做完才推进指针、按天记打卡、自评三档）与页面，
但**不附带任何句库** —— 教材内容是别人的版权物，不能随代码分发。

自己买过课 / 有材料的话，按下面三步把它转成这个模块能读的格式。

## 一、格式：`sentences.json`

放在 `server/data/english/daily-sentence/sentences.json`（`progress.json` 由程序维护，别手改）：

```jsonc
{
  "version": 1,
  "source": "自己填，例如「某某课程 每日一句」",
  "days": [
    {
      "day": 1,
      "title": "第 1 句",              // 可选，不给就显示「第 N 句」
      "en": "The original sentence.",  // 原文（必填）
      "zh": "参考译文",                 // 可选 —— 自评时对照用
      "note": "考点 / 语法点",           // 可选
      "words": [                        // 可选：生词
        { "term": "original", "meaning": "原本的" }
      ]
    }
  ]
}
```

字段原则：**能少填就少填** —— 除了 `en` 之外都是可选的，页面缺哪块就不渲染哪块。
`day` 必须是连续的整数（进度指针按它走）。

## 二、原始材料放哪

```
server/data/english/daily-sentence/
  raw/           ← 把买来的 pdf / docx / 图片放这里（只进不改）
  parsed/        ← 解析器的中间产物（markdown）
  sentences.json ← 最终句库
  progress.json  ← 进度（程序维护）
```

## 三、怎么转

仓库里带了两个转换器，按你的材料形态挑：

**1) 已经用 MinerU（或别的方式）解析成 markdown 了** → 用 `scripts/english-daily-parse.mjs`：

```bash
node scripts/english-daily-parse.mjs
```

它会读 `parsed/*.md`，按内置的切句规则抽出「原文 / 译文 / 考点」，写成 `sentences.json`。
切句规则写在脚本里 —— 不同教材的排版不一样，**大概率要照着你的 markdown 改几行正则**，
改的时候脚本顶部有说明。

**2) 只有 pdf / 图片** → 先过一遍解析，再走上面那步：

- 页面「知识库 → 设置 → 文档解析」里开着云端 MinerU 的话，用知识库的「入库」把文件丢进去，
  解析出来的 markdown 复制到 `parsed/`；
- 或者用任何趁手的 OCR / PDF 工具，只要产出 markdown。

（另一个 `scripts/english-daily-build.mjs` 是从 `parsed/` 生成带更多字段的版本，
如果你的材料里有生词表可以用它。）

## 四、没有句库会怎样

`server/data/english/daily-sentence/` 里没有 `sentences.json` 时，页面的「每日一句 / 句子库」
两个标签会显示空态引导（提示去 `raw/` 放材料、跑解析），不会报错，也不影响「单词」那部分。

## 相关代码

- 数据结构与进度指针：`server/lib/english-daily.mjs`
- 页面：`src/features/vocab/SentenceDaily.vue`（今日训练）/ `SentenceLibrary.vue`（句子库）
- 解析器：`scripts/english-daily-parse.mjs` / `scripts/english-daily-build.mjs`
