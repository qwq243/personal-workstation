# 每日一句：怎么导入自己的句库

「每日一句」是一个**容器**：它带进度逻辑（做完才推进指针、按天记打卡、自评三档）与页面，
但**不附带任何句库** —— 教材内容是别人的版权物，不能随代码分发。

自己买过课 / 有材料的话，按下面两步把它转成这个模块能读的格式。

## 一、格式：`sentences.json`

放在 `server/data/english/daily-sentence/sentences.json`（`progress.json` 由程序维护，别手改）。

**字段名以 `scripts/english-daily-build.mjs` 的产物为准** —— 它就是这份文件的产出者，
边车 `server/lib/english-daily.mjs` 与页面读的也是下面这几个名字：

```jsonc
{
  "version": 1,
  "builtAt": "2026-09-30T00:00:00.000Z",  // 编译时间，脚本自己写
  "source": "导入自本地材料",               // 出处，页面上显示在副标题里
  "total": 120,                            // 共多少天（= days.length）
  "maxDay": 120,                           // 最大 Day 号
  "days": [
    {
      "day": 1,                              // 必填，整数；进度指针按它走
      "text": "The original sentence.",       // 必填：英文原句
      "source": "2005 Text 1",                // 可选：出处（试卷 / 页码），原来是句尾的【…】
      "vocab": [                              // 可选：词汇，**数组**而不是对象
        { "term": "dominant", "pos": "adj.", "meaning": "占优势的；显性的" }
      ],
      "structure": ["① 主句 …", "② 从句 …"],   // 可选：结构划分，一行一条
      "refTranslation": "参考译文。",          // 可选：参考译文（整段一个字符串）
      "grammar": ["语法重点一", "语法重点二"]    // 可选：语法重点 / 翻译要点（别名并进这个字段）
    }
  ]
}
```

字段原则：**能少填就少填** —— 除了 `day` 与 `text` 之外都是可选的，页面缺哪块就不渲染哪块
（`vocab` / `structure` / `grammar` 空数组与 `refTranslation` 空串都算「没有这一块」）。
`day` 尽量连续：编译脚本只**警告**「Day 1..N 里缺哪几天」，但进度指针是按 Day 走的，
缺天会让指针停在一个不存在的句子上。

## 二、原始材料放哪

```
server/data/english/daily-sentence/
  raw/           ← 把买来的 pdf 放这里（只进不改；脚本只认 .pdf）
  parsed/        ← MinerU 出来的 markdown（按 pdf 同名缓存，别手改）
  sentences.json ← 最终句库（编译产物）
  progress.json  ← 进度（程序维护）
```

## 三、怎么转：两步

**1) `raw/*.pdf` → `parsed/*.md`（走云端 MinerU）**

```bash
node scripts/english-daily-parse.mjs
```

它读边车的 MinerU 配置（`config.json` 的 `docparse.mineru` + `credentials.json` 里的令牌），
**把 PDF 上传到 mineru.net**（扫描件必须开 `isOcr`）；`parsed/` 里已有同名且大于 1KB 的 md 就跳过，
所以重跑不会重复花额度。**只有新增 PDF 时才需要跑它。**

**2) `parsed/*.md` → `sentences.json`**

```bash
node scripts/english-daily-build.mjs
```

它按 markdown 的**小节结构**切成一句一份：天边界（`# … DayNN`）、原句、词汇、结构划分、
参考译文、语法重点。脚本顶部注释里有完整结构说明与 **OCR 的三个坑**（换行碎句被误判成小节标题、
词汇释义跨行断开、试卷出处单独成行）。切句规则写死在脚本里 ——
**不同教材的排版不一样，大概率要照着你的 markdown 改几行正则**。
跑完它会打印「编译了多少天」与「哪几块缺失的统计」。

## 四、没有句库会怎样

`server/data/english/daily-sentence/` 里没有 `sentences.json` 时，页面的「每日一句 / 句子库」
两个标签会显示空态引导（提示去 `raw/` 放材料、跑解析），不会报错，也不影响「单词」那部分；
做题本里的「每日一句」那一册（`#/zuotiben/sentence`）同样只有空态。

## 相关代码

- 数据结构与进度指针：`server/lib/english-daily.mjs`（`current()` / `complete()` / `library()` / `sheet()`）
- 页面：`src/features/vocab/SentenceDaily.vue`（今日训练）/ `SentenceLibrary.vue`（句子库）；
  一题一卡的册子与打印页：`src/features/zuotiben/SentenceBook.vue` / `SentenceBookPrint.vue`
- 管线：`scripts/english-daily-parse.mjs`（PDF → markdown）→ `scripts/english-daily-build.mjs`（markdown → 句库）
- 朗读（可选）：边车 `tts` 那一节（本机 edge-tts）；没配就回落浏览器自带朗读
